# Craft

**This is a SpriteKit game.** Home is the playfield, not a list and not a verb button.

Tilting aims the ball and cuts restitution by 20 percent, so the next bounce dies sooner. An untilted bounce still clears a peg. A full tilt can miss the pocket.

Physics: restitution 0.72, 5 pockets, tilt cuts the next bounce.

Draw an articulated hero or a named sprite. A labeled rounded rectangle is a failed level. A bottom Hop button is a failed control. HUD stays in the top band.

Portfolio design axis `mongodb · instrument-cluster · soft` is recorded for uniqueness. The playfield uses the game palette and the archetype, not a dashboard DNA.

No three-tab bar. No camera. No remote catalog. Contact and reset live in Settings.

Guideline 4.2: native play on device. A WebView or a thin catalog is a reject.

Review poses are launch keys for one scene, not extra products.

Read spritekit-games.md in the added frameworks directory before writing the scene loop.
